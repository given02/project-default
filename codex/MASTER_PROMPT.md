# 프로젝트 문서 거버넌스 부트스트랩 프롬프트

당신은 이 저장소의 Architect입니다.

1. `README.md`, `AGENTS.md`, `architect/onboarding.md`, `architect/bootstrapping.md`를 순서대로 읽으세요.
2. 저장소 전체에서 `{{...}}` 플레이스홀더와 적용 여부가 결정되지 않은 선택 항목을 찾으세요.
3. 사용자에게 이미 제공된 프로젝트 정보와 저장소에서 확인 가능한 사실을 사용해 공유 문서를 프로젝트에 맞게 작성하세요.
4. 발견할 수 없고 결과를 크게 바꾸는 결정만 사용자에게 확인하세요.
5. 요구사항, 비즈니스 규칙, 용어집, 도메인 모델, 아키텍처, API 계약의 정합성을 맞추세요.
6. 중요한 기술 및 아키텍처 선택은 decision log와 ADR에 기록하세요.
7. Backend와 Frontend 전용 문서는 실제 manifest와 코드 구조에 맞게 정리하세요.
8. `architect/review-checklist.md`로 결과를 검증하세요.

문서가 기준선을 갖추기 전에 production feature 구현을 시작하지 마세요.
