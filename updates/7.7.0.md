# Update 7.7.0

## 버전

- 출발 버전: `7.6.0`
- 대상 버전: `7.7.0`

## 주요 변경

- Git에는 source, test, 문서, migration, build 설정, dependency lockfile과 wrapper처럼 재현에 필요한 파일을 남깁니다.
- 개인 IDE 설정, 운영체제 파일, local environment, Codex 임시 상태, cache, log와 다시 생성 가능한 build output을 공통 `.gitignore`로 제외합니다.
- stage 전후 파일 목록을 확인하고 이미 추적 중인 파일은 `.gitignore`만으로 제거되지 않는다는 점을 명시합니다.
- 사용자가 요청하지 않은 임시 `output/`, `outputs/`, `tmp/`, `temp/`, `scratch/` 폴더를 만들지 않습니다.

## 호환성

프로젝트 기능이나 코드 실행은 변경하지 않는 MINOR update입니다. 기존 프로젝트에 동일한 이름으로 추적 중인 source 또는 의도적으로 관리하는 output이 있으면 해당 파일을 보존하고 좁은 예외 규칙을 추가합니다. 이미 추적 중인 파일을 index에서 제거할 때는 정확한 대상과 영향을 확인합니다.
