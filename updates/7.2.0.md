# Update 7.2.0

## 버전

- 출발 버전: `7.1.0`
- 대상 버전: `7.2.0`

## 주요 변경

- React 업무·관리 화면에서 Ant Design을 기본 UI library 후보로 검토합니다.
- 일반 목록은 Ant Design Table을 우선하고, 일반 Table로 충족하기 어려운 data grid 요구사항에만 AG Grid Community를 사용합니다.
- Figma 화면 설계의 공통 token을 Ant Design `ConfigProvider`와 AG Grid Theme API에 매핑합니다.
- AG Grid Enterprise package, module과 기능은 사용하지 않습니다.
- 선택한 library, 적용 범위, AG Grid 선택 근거와 theme mapping을 Requirement에 기록합니다.

## 호환성

React 프로젝트가 해당 library를 선택한 경우에만 적용되는 기술별 Standard를 추가하므로 기존 프로젝트와 호환되는 MINOR update입니다.

8. 공개 component API와 theme token을 사용하고 내부 DOM이나 생성 CSS class에 의존하지 않습니다.

10. 정렬, 필터, pagination, selection과 편집 상태의 소유권 및 server API 계약을 명확히 합니다.
