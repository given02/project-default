# Update 7.6.0

## 버전

- 출발 버전: `7.5.0`
- 대상 버전: `7.6.0`

## 주요 변경

- Python source와 type stub에 space 4칸과 100자 line width 기준을 적용합니다.
- repository root의 `.editorconfig`와 `ruff.toml`을 IDE, formatter와 lint의 공통 설정으로 사용합니다.
- Ruff가 줄바꿈, double quote, LF, docstring code, import 정리, unused import와 `E501`을 검증합니다.
- 자동 수정은 `ruff check --fix` 후 `ruff format`, 검증은 `ruff check`와 `ruff format --check` 순서로 통일합니다.
- Agent가 생성한 Python code도 Ruff 검증을 통과해야 Review로 전환할 수 있습니다.

## 호환성

기능과 architecture 의미는 바꾸지 않지만 기존 Python source의 형식, import 순서와 개발 dependency 설정을 변경할 수 있는 호환 가능한 MINOR update입니다. Python source가 있는 프로젝트는 Ruff를 설치하고 기존 source를 기계적으로 정리합니다. Python을 사용하지 않는 프로젝트에는 Ruff dependency를 추가하지 않고 공유 설정과 Standard만 추가합니다.
