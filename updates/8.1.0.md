# 8.1.0 Update

## 출발 버전과 대상 버전

`8.0.0 → 8.1.0`

## 변경 목적

Spring Boot 생성자 주입의 field와 매개변수 이름이 선언 타입을 드러내도록 규칙을 추가합니다. 예를 들어 `PlacesJpaRepository places` 대신 `PlacesJpaRepository placesJpaRepository`를 사용합니다. Application service가 port에 의존하는 구조는 그대로 유지합니다.

## 호환성과 사전 조건

새 규칙을 추가하는 MINOR update입니다. 기존 Spring Boot 코드의 주입 변수명을 변경할 수 있지만 런타임 동작, 주입 대상 bean, API 계약과 저장 구조는 변경하지 않습니다. 같은 타입의 bean이 여러 개이면 이름 변경이 qualifier, 테스트와 설정에 미치는 영향을 먼저 확인합니다. Spring Boot 코드가 없는 프로젝트에서는 템플릿 문서만 갱신합니다.
