# Update 7.9.0

## 버전

- 출발 버전: `7.8.0`
- 대상 버전: `7.9.0`

## 주요 변경

- React Component·UI 통합 테스트의 기본 도구를 Vitest, React Testing Library, user-event와 jest-dom으로 정합니다.
- API를 호출하는 테스트는 MSW로 HTTP 경계를 대체하고 처리되지 않은 요청을 실패로 보고합니다.
- Browser E2E가 필요한 경우에만 Playwright를 도입하고 `src`에 배치한 `*.e2e.spec.ts`를 별도 수집합니다.
- `test`와 선택적 `test:e2e` 실행 명령, CI 및 Requirement 테스트 결과 기록 기준을 정합니다.
- Frontend Review 기준에 사용자 동작, 관련 상태, 오류·권한 경로와 계획된 E2E 검증을 추가합니다.

## 호환성

기존 Frontend 테스트 코드와 runner 설정의 변경이 필요할 수 있는 MINOR update입니다. 변경된 테스트의 검증 범위를 줄이거나 기존 테스트를 삭제하지 않습니다. React Frontend가 없는 프로젝트에는 도구 dependency를 추가하지 않고 템플릿 문서만 갱신합니다.
