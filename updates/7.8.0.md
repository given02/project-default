# Update 7.8.0

## 버전

- 출발 버전: `7.7.0`
- 대상 버전: `7.8.0`

## 주요 변경

- Java 기반 Spring Boot의 단위, Web/API와 필요한 통합 테스트를 모두 `src/test/java`에서 관리합니다.
- React의 Component와 UI 통합 테스트 및 필요한 browser E2E 테스트를 검증 대상의 `src` 기능 가까이에 둡니다.
- 별도 `backend/src/integrationTest` source set과 `frontend/e2e` directory를 만들지 않습니다.
- `test-results/`, `playwright-report/`, `blob-report/` 같은 실행 결과를 Git에서 제외합니다.

## 호환성

테스트의 검증 책임은 유지하지만 기존 별도 테스트 source set과 directory를 사용하는 프로젝트에서는 테스트 위치, build·runner 설정과 실행 명령을 변경해야 하는 MINOR update입니다. 이전 테스트를 제거하거나 검증 범위를 줄이지 않습니다.
