# 8.0.0 Update

## 출발 버전과 대상 버전

`7.9.0 → 8.0.0`

## 변경 목적

- 요구사항 정의서, 기능 명세서, DB 테이블 정의서, 테스트 시나리오 및 결과서의 기본 형식을 Microsoft Excel에서 Google Sheets로 전환합니다.
- 각 산출물은 별도의 Google Sheets 스프레드시트로 유지하고 화면 설계는 Figma를 사용합니다.
- Google Drive 앱으로 원본을 확인하고 지원되는 Sheets 기능으로 필요한 범위만 편집·재확인합니다.
- 기존 프로젝트의 Excel 파일과 링크는 검증 없이 삭제하거나 Google Sheets 링크로 치환하지 않습니다.

## 호환성과 사전 조건

외부 산출물의 형식과 접근 서비스가 바뀌는 MAJOR update입니다. 기존 프로젝트에서 Microsoft Excel 산출물을 사용한다면 사용자에게 대응하는 Google Sheets 편집 링크를 받아 데이터·ID·이력을 검증한 후 전환합니다. 필수 산출물의 링크 또는 내용이 아직 이전되지 않았다면 버전을 올리지 않고 필요한 사용자 조치를 안내합니다. 화면이나 Database가 없는 프로젝트는 해당 항목에 `해당 없음`을 유지할 수 있습니다.
