# 8.2.0 Update

## 출발 버전과 대상 버전

`8.1.0 → 8.2.0`

## 변경 목적

- Spring Data JPA의 기본 repository method와 읽기 쉬운 derived query를 단순 조회에 사용합니다.
- 길거나 복잡한 조건·join·projection·정렬·pagination 조회는 infrastructure의 QueryDSL 구현으로 분리하고 `@Query` annotation은 사용하지 않습니다.
- 일반적인 use case transaction에는 application service의 public method에 `@Transactional`을 사용합니다.
- `TransactionTemplate`은 method 내부에서 시작·종료 범위를 명시적으로 제어해야 하는 드문 경우에만 허용하고 self-invocation 우회책으로 사용하지 않습니다.

## 호환성과 사전 조건

기존 JPA 구현의 변경이 필요할 수 있는 MINOR update입니다. `@Query`가 있는 프로젝트에서는 쿼리 결과, 정렬, pagination, locking, bulk 동작과 실제 Database 테스트를 보존해야 합니다. QueryDSL이 필요할 때만 호환되는 dependency와 Q-type generation을 추가합니다. Spring Data JPA를 사용하지 않는 프로젝트는 템플릿 문서만 갱신합니다. 자동 변환으로 쿼리 의미나 transaction 경계를 확인할 수 없으면 버전 전환을 완료하지 않습니다.
