# Update 7.5.0

## 버전

- 출발 버전: `7.4.0`
- 대상 버전: `7.5.0`

## 주요 변경

- Java 기반 Spring Boot 프로젝트에서 Lombok을 기본 사용해 반복 코드를 줄입니다.
- Spring component는 `final` dependency와 `@RequiredArgsConstructor`, logging은 `@Slf4j`, 단순 접근자는 `@Getter`를 우선 사용합니다.
- domain과 JPA entity에는 class 단위 `@Data`·`@Setter`를 금지하고 entity 생성, equality와 `toString`의 안전 규칙을 적용합니다.
- `@SneakyThrows`와 Lombok `val`·`var`는 루트 `lombok.config`에서 error로 차단합니다.
- Java source는 `.editorconfig`의 space 4칸과 100자 기준을 사용합니다.
- Spotless와 version이 고정된 `google-java-format`으로 줄바꿈, import와 형식을 build에서 검증합니다.
- Agent가 생성한 Java code도 formatter를 통과해야 Review로 전환할 수 있습니다.

## 호환성

기능과 architecture 의미는 바꾸지 않지만 기존 Java source의 형식과 build 설정을 변경할 수 있는 호환 가능한 MINOR update입니다. 기존 프로젝트에 Java 기반 Spring Boot module이 있으면 Lombok과 Spotless를 설정하고 Java source를 기계적으로 format합니다. 다른 언어 또는 Spring Boot를 사용하지 않는 module에는 Java 전용 dependency를 추가하지 않습니다.

[Lombok Standard]

standards/backend/spring-boot/BE-SPR-07-lombok-convention.md를 만들고 STD-BE-SPR-070부터 STD-BE-SPR-079까지 다음 의미를 빠짐없이 정의하세요.

1. Java 기반 Spring Boot는 Lombok과 annotation processor의 명시적 version을 기본 사용합니다.
2. Spring component dependency는 final field와 @RequiredArgsConstructor로 constructor injection합니다.
3. @Getter를 우선 사용하고 @Setter는 실제 변경이 필요한 field로 제한합니다.
4. logging field는 @Slf4j로 생성하되 기존 보안 logging 규칙을 지킵니다.
5. immutable data carrier는 @Value 또는 record를, @Data는 모든 생성 동작이 실제 계약인 mutable carrier에만 사용합니다.
6. @Builder는 validation이 있는 constructor 또는 factory에 적용하고 domain·entity 생성 규칙을 우회하지 않습니다.

8. JPA 기본 생성자는 @NoArgsConstructor(access = AccessLevel.PROTECTED)를 사용하고 force = true를 금지합니다.
9. JPA equality, hashCode와 toString은 연관관계, lazy loading과 mutable field를 자동 포함하지 않으며 명시 include 또는 직접 구현을 사용합니다.
10. @SneakyThrows와 Lombok val·var를 금지하고 build compile 또는 delombok으로 생성 결과를 확인합니다.
