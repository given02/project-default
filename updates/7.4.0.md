# Update 7.4.0

## 버전

- 출발 버전: `7.3.0`
- 대상 버전: `7.4.0`

## 주요 변경

- 새 Architect 주 컨텍스트의 기본값을 `gpt-6-sol`, reasoning `high`로 설정합니다.
- Backend와 Frontend Developer Agent의 기본값을 `gpt-6-luna`, reasoning `medium`으로 설정합니다.
- 프로젝트별 `.codex/config.toml`에서 Architect 기본 모델을 실제로 적용합니다.
- 사용자의 명시적인 컨텍스트별 모델 선택은 기본값보다 우선합니다.
- `gpt-6-astra`는 기본값이나 자동 fallback으로 사용하지 않고 사용자가 명시적으로 선택할 때만 사용합니다.
- 지정 모델을 사용할 수 없으면 임의 모델로 대체하지 않고 사용자에게 선택을 요청합니다.

## 호환성

역할, 상태 전이와 구현 절차는 유지하고 역할별 기본 모델만 변경하는 호환 가능한 MINOR update입니다. 기존에 실행 중인 컨텍스트의 모델을 바꾸지 않으며 새 컨텍스트부터 프로젝트 기본값이 적용됩니다.
