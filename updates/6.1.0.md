# Update 6.1.0

## 버전

- 출발 버전: `6.0.0`
- 대상 버전: `6.1.0`

## 주요 변경

- OneDrive와 SharePoint의 Microsoft Excel 원본은 SharePoint 앱을 기본 접근 수단으로 사용합니다.
- SharePoint 앱 연결, 파일 권한, 지원 action, Excel 정밀 편집과 반영 검증 순서를 표준화합니다.
- Figma 원본도 앱 연결과 권한을 먼저 확인합니다.
- `customs/PROJECT.md`에 외부 문서 접근 수단과 상태를 기록합니다.
- 이후 버전을 순차적으로 적용할 수 있도록 `updates/` 운영 체계를 추가합니다.
- 앞으로 모든 새 버전에서 `updates/<대상 버전>.md` 마이그레이션 프롬프트 작성을 필수화합니다.
