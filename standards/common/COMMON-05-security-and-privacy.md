# Security And Privacy

## 기준

- **STD-COMMON-050** 인증은 사용자나 시스템의 신원을 확인하고 인가는 보호된 작업마다 서버 또는 자원 소유 경계에서 검증합니다.
- **STD-COMMON-051** 모든 입력은 신뢰하지 않으며 경계에서 형식, 범위, 크기와 권한을 검증합니다.
- **STD-COMMON-052** 계정, 애플리케이션과 운영 도구에는 필요한 최소 권한만 부여합니다.
- **STD-COMMON-053** secret, credential과 token을 소스 코드, 문서, migration, fixture와 client bundle에 저장하지 않습니다.
- **STD-COMMON-054** 민감정보는 수집 목적과 보존 기간을 정의하고 필요한 최소 범위만 저장합니다.
- **STD-COMMON-055** 비밀번호와 인증용 비밀은 원문을 저장하지 않고 용도에 맞는 검증된 단방향 방식으로 보호합니다.
- **STD-COMMON-056** 로그와 오류 응답은 내부 구조, credential과 불필요한 개인정보를 노출하지 않습니다.
- **STD-COMMON-057** 개인정보의 접근, 수정, 삭제, 보존과 복구는 Customs의 데이터 생명주기와 일치해야 합니다.
- **STD-COMMON-058** 개발과 테스트에 운영 데이터가 필요하면 비식별화하고 접근을 제한합니다.
