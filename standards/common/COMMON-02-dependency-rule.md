# Dependency Rule

## 기준

- **STD-COMMON-020** 의존성은 구체적인 기술과 전달 수단에서 제품 의미와 안정적인 내부 정책 방향으로 흐릅니다.
- **STD-COMMON-021** 컴포넌트는 문서화된 인터페이스를 통해 통신하고 다른 컴포넌트의 내부 구현에 의존하지 않습니다.
- **STD-COMMON-022** 순환 의존성을 만들지 않습니다.
- **STD-COMMON-023** 공유 코드는 실제로 둘 이상의 소유 영역에서 같은 의미와 변경 주기를 가질 때만 추출합니다.
- **STD-COMMON-024** 공유 계약의 변경은 소비자 영향과 호환성, 배포 순서를 함께 검토합니다.
- **STD-COMMON-025** 새로운 컴포넌트 간 의존성이나 공유 계약이 필요하면 구현 전에 현재 Requirement의 기능 명세와 계약을 갱신합니다.
- **STD-COMMON-026** 테스트 편의를 위해 production 의존성 방향을 뒤집지 않고 경계의 인터페이스와 대체 구현을 사용합니다.
