# Code Quality

## 기준

- **STD-COMMON-030** 이름은 구현 수단보다 도메인 의미와 책임을 드러냅니다.
- **STD-COMMON-031** 함수, 클래스와 모듈은 하나의 변경 이유와 설명 가능한 책임을 가집니다.
- **STD-COMMON-032** 중복 제거보다 명확한 소유권과 결합도 감소를 우선하며 우연히 비슷한 코드를 성급히 공통화하지 않습니다.
- **STD-COMMON-033** 주석은 코드가 무엇을 하는지 반복하지 않고 제약, 의도와 선택 이유를 설명합니다.
- **STD-COMMON-034** 오류를 무시하거나 정상 값으로 위장하지 않고 호출자가 처리할 수 있는 형태로 전달합니다.
- **STD-COMMON-035** 로그에는 문제를 추적할 맥락을 포함하되 secret, credential, token과 불필요한 개인정보를 기록하지 않습니다.
- **STD-COMMON-036** formatter와 lint 규칙은 자동화하고 개인 취향에 따라 파일별로 우회하지 않습니다.
- **STD-COMMON-037** 사용하지 않는 코드, 주석 처리된 코드와 임시 우회는 완료된 구현에 남기지 않습니다.
- **STD-COMMON-038** dependency 추가는 기존 기능으로 해결 가능한지, 유지보수 상태, 보안, 크기와 교체 비용을 검토한 뒤 수행합니다.
