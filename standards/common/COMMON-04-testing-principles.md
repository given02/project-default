# Testing Principles

## 기준

- **STD-COMMON-040** 테스트는 구현 세부사항보다 외부에서 관찰 가능한 동작과 비즈니스 규칙을 검증합니다.
- **STD-COMMON-041** 변경한 동작에는 정상 경로뿐 아니라 중요한 경계값, 실패와 권한 경로를 검증하는 테스트를 포함합니다.
- **STD-COMMON-042** 단위 테스트는 빠르고 격리된 규칙 검증에, 통합 테스트는 실제 경계와 기술 동작 검증에 사용합니다.
- **STD-COMMON-043** mock은 소유하지 않은 경계나 느린 외부 의존성을 격리할 때 사용하며 테스트 대상의 내부 호출 순서를 과도하게 고정하지 않습니다.
- **STD-COMMON-044** 시간, 난수, 네트워크와 병렬 실행에 의존하는 테스트는 제어 가능한 입력으로 만들어 반복 실행 결과가 같게 합니다.
- **STD-COMMON-045** production 결함을 수정할 때는 가능하면 결함을 재현하고 재발을 막는 테스트를 먼저 추가합니다.
- **STD-COMMON-046** 테스트 데이터는 각 테스트의 의도를 드러내고 다른 테스트의 실행 순서나 잔여 상태에 의존하지 않습니다.
- **STD-COMMON-047** 실행하지 못한 테스트와 환경 차이는 검증 결과에 명시하며 성공으로 보고하지 않습니다.
