# Architect

## 목적

Architect가 소유하는 거버넌스, 온보딩, 계획과 의사결정을 관리합니다.

## 내용

- `onboarding.md`: 사람과 Codex 컨텍스트의 온보딩
- `bootstrapping.md`: Architect 작업 시작 방법
- `governance.md`: 소유권, 에스컬레이션, 승인 규칙
- `git-convention.md`: Git commit 단위와 메시지 규칙
- `feature-lifecycle.md`: 아이디어부터 릴리스까지의 흐름
- `review-checklist.md`: 문서 및 아키텍처 검토 기준
- `roadmap.md`: 제품 방향과 마일스톤
- `backlog.md`: 구현 독립적인 기능 후보
- `decision-log.md`: 지속적인 결정 인덱스
- `decision-template.md`: ADR 템플릿
