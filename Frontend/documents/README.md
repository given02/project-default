# Frontend Documents

## 목적

Frontend에만 적용되는 환경, 폴더, 코드, UI, routing, state와 API client 규칙을 관리합니다.

## 문서

- `project-environment.md`: runtime, build, dependency와 환경
- `folder-structure.md`: 폴더와 feature 경계
- `frontend-convention.md`: framework 및 component 규칙
- `typescript-convention.md`: TypeScript 규칙
- `routing.md`: route와 navigation 규칙
- `state-management.md`: local, global과 server state 소유권
- `api-client.md`: API 호출과 오류 처리
- `ui-convention.md`: 디자인, 접근성과 responsive 규칙

## 경계

제품 요구사항, 도메인 의미와 API 계약은 `../../documents/`를 참조합니다.
