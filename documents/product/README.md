# Product

## 목적

제품의 사용자 가치, 범위, 요구사항과 비즈니스 규칙을 관리합니다.

## 문서

- `requirements.md`: 기능별 사용자 가치, 범위와 acceptance criteria
- `business-rule.md`: 구현 기술과 독립적인 제품 규칙과 invariant

## 원칙

- 모든 production feature는 승인된 요구사항에서 시작합니다.
- 요구사항은 구현 방법보다 사용자 관점의 결과를 설명합니다.
- 비즈니스 규칙은 Backend와 Frontend 문서에 복사하지 않습니다.
