# Architecture

## 목적

프로젝트 수준의 도메인, 시스템 경계, 의존성과 주요 흐름을 관리합니다.

## 문서

- `domain-model.md`: 핵심 개념과 관계
- `architecture.md`: 컴포넌트와 책임 경계
- `dependency-rule.md`: 허용되는 의존성 방향
- `authentication-flow.md`: 인증을 사용할 경우의 공유 흐름

## 원칙

역할별 패키지와 폴더 규칙은 Backend 또는 Frontend 문서에서 관리하고, 프로젝트 전체 의미와 경계만 이 디렉터리에서 관리합니다.
