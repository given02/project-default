# Documents

## 목적

Architect가 소유하는 프로젝트 수준의 공유 지식을 관리합니다. Backend와 Frontend는 이 문서를 참조하지만 공유 개념을 각자 문서에서 재정의하지 않습니다.

## 내용

- `product/`: 요구사항과 비즈니스 규칙
- `glossary/`: 표준 용어
- `architecture/`: 도메인 모델, 시스템 구조와 의존성
- `api/`: Backend와 Frontend 사이의 API 계약
- `adr/`: 장기적인 아키텍처 결정
- `roles/`: 역할 책임과 경계
