# User Flows

## 작성 규칙

- 사용자 행동과 시스템 반응을 한 단계씩 구분합니다.
- 성공 경로뿐 아니라 validation, 권한, 취소, 재시도와 복구 경로를 정의합니다.
- 화면 내부 구현보다 사용자가 관찰하는 결과를 작성합니다.

## 완료 기준

- 각 Flow가 Requirement와 Screen에 연결됩니다.
- 모든 단계에 사용자 행동과 시스템 반응이 있습니다.
- 실패 후 사용자가 다음에 할 수 있는 행동이 정의되어 있습니다.
- Backend와 Frontend가 같은 성공 및 실패 조건을 이해할 수 있습니다.
